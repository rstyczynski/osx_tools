= OSX Tools

== TimeMachine Simplified 

TimeMachine Simplified is a file backup tool. Supports full and incremental copies, with a final report showing one row per source.

Version 1.6.0. See link:tms/README.adoc[the tms README] and link:tms/CHANGELOG.adoc[changelog].

=== Features

* *Full and incremental backups*, with timestamped snapshots and hard links.
* *Batch backups* of all sources already known at the destination using `tms --all`.
* *Central exclusions and local overrides* with `.tmsignore` include exceptions, excluded-file counts, and `tms --explain`.
* *Source inventory* showing state, size, file count, and last backup using `tms --sources`.
* *Per-source reports* showing status, changed files, duration, and snapshot details.
* *Native macOS scheduling* every four hours, with catch-up after sleep and on/off/status controls.
* *SwiftBar integration* showing status and backup-now actions for all or individual sources.
* *Formatted email summaries* with aligned Courier tables and scheduler information.
* *Snapshot restore* to a separate destination.
* *Agent-assisted source optimization* through an optional review guide and example prompts for your own agentic layer.
* *Guided macOS access setup* and an automated background-access check.
* *Overlap protection* for scheduled and menu-triggered backups, with saved logs and summaries.

See link:tms/README.adoc[the TMS documentation] for commands and setup.

=== Usage

```
source tms.sh

backup_volume=/Volumes/Backup
tms src_dir [full]
tms --all          # Back up existing sources discovered at the destination
tms --sources      # List source state, size, files, and last successful backup
tms --explain /path/to/file --source /backup/source
tms --scheduler on|off|status
tms --swiftbar on|off|status
tms --access setup|status
tms --version
```

=== Requirements
Target backup volume file systems supports hard links.

=== Limitations

* Modification dates and Unix permission bits are preserved, but creation dates,
  ACLs, and extended attributes are not fully preserved.
* Symbolic links are copied as their targets; original hard-link relationships
  are not preserved through backup and restore.
* Incremental backups retain source-deleted files; explicit exclusions apply to new snapshots.
* *Known correctness bugs:* same-size changes with unchanged modification dates
  can be missed, and later permission changes can alter earlier snapshots' metadata.
* Restore copies the stored snapshot and absolute-path tree into a new destination.

See link:tms/README.adoc#limitations[the verified limitations and known correctness bugs]
for details. The two correctness bugs remain present in version 1.6.0.
